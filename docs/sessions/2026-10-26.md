## E. Hooks — the quality gates we keep hitting

`.openhands/hooks.json`:
```json
{
  "pre_tool_use": [
    { "matcher": "terminal", "hooks": [ { "command": ".openhands/hooks/guard.sh", "timeout": 10 } ] }
  ],
  "stop": [
    { "matcher": "*", "hooks": [ { "command": ".openhands/hooks/quality_gate.sh", "timeout": 180 } ] }
  ]
}
```
- `guard.sh`: reads the JSON on stdin; denies `rm -rf /`, `git push --force` to `main`, `--no-verify`, and any `git push` whose staged content matches the secret patterns.
- `quality_gate.sh`: runs the real gate (tsc strict, lint, build) and returns `{"decision":"deny","reason":...}` with exit 2 if it fails — this is what stops us from ever reporting "green" without proof.
