## Root cause

The Stop hook was **wrong**, and `git push` could never satisfy it. This sandbox clone ships a **narrow fetch refspec**:

```
remote.origin.fetch = +refs/heads/main:refs/remotes/origin/main
```

That maps **only `main`**. So pushing my feature branch never created `refs/remotes/origin/docs/teaching-agents-skills-report`, and `git rev-parse '@{u}'` failed with *"upstream branch not stored as a remote-tracking branch."* The hook then fell through to its fallback `git rev-list --count origin/main..HEAD` → **1** (my one legitimately-new commit) and denied forever. `git push -u origin HEAD` set the branch config but could not invent a tracking ref the refspec refuses to fetch — hence "Everything up-to-date" yet still denied.

## Fix

One config line plus a fetch:

```
git config remote.origin.fetch '+refs/heads/*:refs/remotes/origin/*'
git fetch origin
```
