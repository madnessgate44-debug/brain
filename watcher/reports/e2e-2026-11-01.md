## What is NOT proven
- No backend is deployed to the public internet. The GitHub Pages site serves static HTML only;
  it has no reachable Brain API behind it, so the hosted page cannot run a real chat/mission.
- The company workflow (`POST /company-workflows`) needs `BRAIN_GITHUB_TOKEN` and a repo; not exercised here.
- The browser worker needs the optional `[browser]` extra and a manual login; not exercised.
- `chromium-smoke` CI check fails on GitHub's ubuntu-26.04 image: Playwright 1.52 cannot install
  chromium there. Environment issue, unrelated to app code.

## Notes
- The 502 on the first chat call was a wrong model name in the test (`gemini-2.0-flash` does not
  exist). With the configured `gemini-3.5-flash-lite` it returns 200. Config error, not an app defect.
