### Vercel recipe (learned)
- `npm i -g vercel` fails (no root write to /usr/local). Install locally:
  `mkdir /tmp/vtool && cd /tmp/vtool && npm init -y && npm install vercel`, then
  `PATH=/tmp/vtool/node_modules/.bin:$PATH`.
- Deploy: `vercel deploy --prod --yes --token "$VERCEL_TOKEN" --scope forge-fe22`.
  Do NOT set `VERCEL_ORG_ID` alone → CLI errors "you forgot VERCEL_PROJECT_ID".
- Python entrypoint: `app.py|index.py|server.py|main.py|wsgi.py|asgi.py` at root,
  `src/`, or `app/`; must define module-level `app`.
- Python bundle limit **500 MB uncompressed** (not 250). litellm alone is 149 MB and
  openhands-sdk pulls it → requirements.txt is the LEAN set (no openhands-sdk/litellm);
  Dockerfile installs the full set. API/connector do NOT import openhands/litellm at
  request time (verified).
- **Vercel FS read-only except `/tmp`.** Import-time config `Path.mkdir('./workspace')`
  → `OSError: [Errno 30] Read-only file system`. Fix with env:
  `WORKSPACE__ROOT=/tmp/brain/workspace`,
  `DATABASE__SQLITE_PATH=/tmp/brain/workspace/db/brain.db`,
  `LOGGING__LOG_FILE=/tmp/brain/workspace/logs/brain.log`.
- Env vars: `POST https://api.vercel.com/v10/projects/{id}/env?teamId=` body
  `{key,value,type:"encrypted",target:["production","preview","development"]}` → 201.
  Redeploy after setting.
- Logs: `vercel logs <url> --scope forge-fe22 --token "$VERCEL_TOKEN"`.
- **/tmp is ephemeral** → missions/artifacts do NOT survive cold starts on Vercel;
  chat does. Durable path = container + mounted volume.

### MCP server gotcha (real bug, fixed)
- `FastMCP(stateless_http=True).streamable_http_app()` creates a
  `StreamableHTTPSessionManager` whose lifespan runs `anyio.create_task_group()`.
  That task group **must be entered and exited in the same task**; entering it in a
  request task raises `RuntimeError: Attempted to exit cancel scope in a different
  task than it was entered in` and hangs on warm serverless reuse.
- Fix in `CombinedApp`: run the connector lifespan in a **dedicated long-lived asyncio
  task** (`_run_mcp_lifespan` + `_mcp_started`/`_mcp_stop` Events) and start lazily on
  first request. Guard with `asyncio.Lock`. Verified: startup once → 3 cross-task
  `tools/list` → clean shutdown.
