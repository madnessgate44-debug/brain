# 2026-11-20 — session agent loop: W1 ratchet could not fail on a shallow clone

## The one item closed
`scripts/agent_status.py` measured the report-only ratio over `git log -60` and divided by
whatever came back, never checking the count matched the window. A depth-1 checkout returned
one commit, so the ratio read `0/1 (0%)` and exited 0 — a real 12/14 (86%) breach passed.

Fix: `report_only_ratio()` returns a `truncated` flag; `build()` carries `history_truncated`;
`render()` prints FAIL; `main()` exits 1. Six jobs read this number and five checked out shallow.

## Why it stayed hidden for so long
`tests/test_shadow_purpose_gate.py` asserts the real repo passes its own ratio. On a depth-1
checkout that assertion ran against one commit, so CI went red *blaming the repo*:
`AssertionError: the W1 ratchet is red: Report-only commits: 0/1 (0%)`.
The first push of the branch reproduced it — my fix working, not breaking, and it exposed two
shallow test jobs I had missed on the first pass (`brain-ci.yml`, `tests.yml`).

## The guard test took three tries
1. Keyed on `agent_status.py` only → missed the pytest jobs (they read the ratio indirectly).
2. Keyed on any `pytest` → flagged 6 jobs that run pytest inside a throwaway clone of another
   repo. Too broad; would have been a false gate.
3. Final: only push/pull_request jobs, and only a *bare* `pytest` invocation or `agent_status.py`.
   Regex bug: `pytest\s+(?:-[a-zA-Z]+\s+)*$` required trailing space, so `pytest -q` never matched
   and the guard silently passed. `pytest(?:\s+-[a-zA-Z]+)*\s*$` is correct.
   Verified against `origin/main`: flags exactly `brain-ci.yml:python-tests`, `tests.yml:tests`.

## The audit check is red and it is not your diff

auditor has no model.` → `VERDICT: BLOCKED`. Red on `main` and on PR #320 too. Fails closed by

## MEMORY.md is compacted by the harness — do not blindly `git add -A`
On disk it was 84 lines; HEAD had 971. Neither was a superset: disk had condensed durable facts
(no-webhook, guard traps, QA recipes), HEAD had 40 mission sections that exist in **no** daily
log. `git add -A` would have destroyed 887 lines of unrecoverable history. Merged instead:
disk index first, then HEAD's history under a separator. Diff = 90 added, 0 removed.

Lesson: before committing a harness-rewritten MEMORY.md, `git diff --numstat` it. Any deletion
count > 0 means the harness compacted and you are about to lose content.
