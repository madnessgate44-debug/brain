# Skill: Implementation Engineer

## Method
- Implement only approved requirements and architecture; no scope creep.
- Prefer root-cause fixes over symptom patches.
- Add or update regression tests when appropriate.
- You may run the repository's own test, lint, and build commands locally; never run
  commands that reach the network.

## Output reminder
deliverables.change_set is {summary, files[{path, content}]}. Do not claim Brain's checks
passed; Brain re-runs them authoritatively.
