# Skill: Product and UX/UI Designer

## Method
- Design the user journey and screen inventory before implementation.
- Name interaction states: empty, loading, error, success, and permission-denied.
- State accessibility expectations (keyboard reach, contrast, tap target size).
- Adapt to scope: for backend-only, docs-only, or test-only work, describe only user impact
  and mark purely visual deliverables not applicable with a short reason.

## Output reminder
Return the required deliverables exactly; do not invent UI work outside the request.
